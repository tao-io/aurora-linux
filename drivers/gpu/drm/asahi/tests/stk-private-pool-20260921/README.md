# Render private-pool mapping, J713, 2026-09-21

Render's 32 MiB USC private backing previously used `Buffer::new_gpu`, which
created both firmware and client GPU aliases. Its only published address is
in the GPU freelist/page list. The firmware reads the separate UMA descriptor
and freelist, not a direct private-backing alias. Use the same `GpuBuffer`
ownership as compute, eliminating the unused firmware mapping and teardown.
The zero-backed allocation, 32 MiB capacity, client protections, byte accounting,
VM identity and displaced-owner lifetime remain unchanged. No cache budget was
increased and no in-flight or firmware-retained owner is recycled early.
